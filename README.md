# Interactive Online Technologies — Test Suite

Playwright + TypeScript. Покрыты основные пользовательские сценарии.

## Что тестируется

### UI (E2E)
**Регистрация** - успешная регистрация (мужской/женский пол, с фото и без), валидация обязательных полей, навигация на страницу входа.

**Логин** - успешный вход, неверный пароль, пустые поля, навигация на регистрацию.

### API
**Auth** - дубликат email возвращает 409, неверные credentials возвращают 400, несуществующий email возвращает 400.

> **Заметка:** при попытке зарегистрировать дубликат email и при неверных credentials на странице логина UI не показывает пользователю никакой ошибки (баг приложения). По этой причине эти сценарии вынесены на API уровень - там ошибки возвращаются корректно.

## Запуск

```bash
npm install
npx playwright test
npx playwright show-report
```
